# 파일 시스템
## inode
```
[디렉토리 엔트리]              [inode #1234]                 [데이터 블록]
 "a.txt" → 1234   ───────→ 종류, 권한, 소유자, 크기, 링크수.. ───→  "hello\n"

```

- 링크 수 :
  - inode를 가리키는 디렉토리 엔트리의 개수
  - 링크 수가 0, 해당 파일을 연 fd도 0 => 커널이 데이터를 해제

```bash
echo hello > orig.txt

ls -li orig.txt
# # 56748 -rw-r--r-- 1 di di 6 Oct 15 17:22 orig.txt
# inode    권한   링크 수

ls -l orig.txt
# -rw-r--r-- 1 di di 6 Oct 15 17:22 orig.txt
```

- -p : (또는 --parents) 옵션은 상위(부모) 디렉터리가 없을 때 자동으로 함께 생성해 주는 기능
- `ls -l`에 `-i`를 붙이면 inode 번호 추가

## 하드링크 vs 심볼릭 링크

### 하드링크
- 같은 inode를 가리키는 이름 추가
- 원본과 복사본의 구분 X

```bash
ln orig.txt hard.txt # 같은 inode에 이름 추가
ls -li orig.txt hard.txt
# # 56748 -rw-r--r-- 2 di di 6 Oct 15 17:22 hard.txt
# # 56748 -rw-r--r-- 2 di di 6 Oct 15 17:22 orig.txt
# 링크 수가 올라간 것을 확인할 수 있다.
```

### 심볼릭링크
- 자기만의 inode를 가진 파일.
- 내용은 경로 문자열 -> 크기 = 글자 수
- 원본 삭제 시 끊긴 링크(dangling)이 된다.
- window의 바로가기 (.lnk) 와 가장 유사.
  - 단 lnk는 탐색기만 해석.
  - 심볼릭 링크는 커널이 따라가므로 cat같은 모든 프로그램에서 동작

```bash
ln -s orig.txt soft.txt
ls -li orig.txt hard.txt soft.txt
# 56748 -rw-r--r-- 2 di di 6 Oct 15 17:22 hard.txt
# 56748 -rw-r--r-- 2 di di 6 Oct 15 17:22 orig.txt
# 56788 lrwxrwxrwx 1 di di 8 Oct 15 17:51 soft.txt -> orig.txt
```

```bash
rm orig.txt
ls -li hard.txt soft.txt
# 56748 -rw-r--r-- 1 di di 6 Oct 15 17:22 hard.txt
# 56788 lrwxrwxrwx 1 di di 8 Oct 15 17:51 soft.txt -> orig.txt

cat hard.txt
# hello

cat soft.txt; echo "rc=$?"
# 커널이 메모를 자동으로 따라가 해당 메모를 연다. 하지만 orig.txt가 삭제되어 실패
# cat: soft.txt: No such file or directory
# rc=1

```
